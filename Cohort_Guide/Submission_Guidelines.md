# 📤 Cohort Submission Guidelines

## 🎯 Purpose

These submission guidelines are designed to keep every member consistent, organized, accountable, and portfolio-ready throughout the learning journey.

Every submission should show:
- understanding
- effort
- manual reasoning
- Excel/tool implementation
- insight extraction
- documentation discipline

---

# 📌 Required Daily Deliverables

Every member MUST submit the following for each day's topic:

1. Completed Excel Analysis Sheet
2. Manual Practice Sheet
3. README.md
4. Insights Summary
5. Screenshots/Charts where applicable
6. Reflection Notes

---

# ✅ 1. Completed Excel Analysis Sheet

The completed Excel analysis sheet must contain:

- the solved dataset
- correct formulas
- clearly labeled outputs
- organized formatting
- charts or visuals where required
- validation checks where applicable

The file should be saved inside:

```text
Completed_Analysis/
```

Recommended file name:

```text
Day_XX_Completed_Analysis.xlsx
```

---

# 🧮 2. Manual Practice Sheet

The manual practice sheet must show:

- formula logic
- handwritten or typed calculations
- step-by-step reasoning
- explanation of manual process
- interpretation of results

The file should be saved inside:

```text
Manual_Practice/
```

Recommended file names:

```text
Day_XX_Manual_Practice.md
Day_XX_Manual_Practice.pdf
```

---

# 📝 3. README.md

Each day folder must include a README.md file.

The README should explain:

- objective
- dataset description
- concepts learned
- formulas used
- analysis process
- insights extracted
- challenges faced
- outcome

The README should be clear enough for someone outside the cohort to understand the work.

---

# 💡 4. Insights Summary

Each member must submit an insight summary containing at least:

- 3 observations
- 3 interpretations
- business meaning
- recommendation where applicable

The file should be saved inside:

```text
Insights/
```

Recommended file name:

```text
Day_XX_Insights.md
```

---

# 🖼️ 5. Screenshots / Charts

Screenshots should be submitted where applicable.

Screenshots may include:

- charts
- pivot tables
- formula outputs
- dashboards
- Excel tables
- key calculations

The file should be saved inside:

```text
Screenshots/
```

---

# 🪞 6. Reflection Notes

Each member should write a short reflection explaining:

- what was learned
- what was difficult
- how the difficulty was handled
- what needs improvement
- how the topic applies to data analysis

Reflection may be included in the README or saved separately.

---

# 📂 Submission Folder Structure

Each day should follow this structure:

```text
Day_XX_Topic_Name/
│
├── Raw_File/
├── Completed_Analysis/
├── Manual_Practice/
├── Screenshots/
├── Insights/
└── README.md
```

---

# 📌 Submission Rules

Every member must:

- submit work on time
- use proper folder names
- use proper file names
- complete manual practice before relying on Excel
- validate answers before submission
- include business interpretation
- document challenges honestly
- avoid copying AI-generated answers blindly
- keep GitHub repositories organized
- update work consistently

---

# 👥 Group Learning Rules

## ✍️ 1. Attempt Before Asking

Each member should attempt the task before asking for help.

The goal is to develop problem-solving ability.

---

## ❓ 2. Ask Clear Questions

Questions should include:
- what you tried
- where you got stuck
- the formula or method used
- screenshot or result where possible

---

## ⏰ 3. Respect Review Time

Submissions should be made early enough for review and feedback.

---

## 🗂️ 4. Do Not Overwrite Old Work

Always keep previous work unless instructed otherwise.

If you update a file, use a clear version name or commit message.

---

## 🧠 5. Keep Work Original

Members may discuss ideas, but each person must write their own:
- README
- reflection
- insights
- interpretation

---

## 🤖 6. Use AI Responsibly

AI may be used for:
- explanations
- debugging
- insight refinement
- study support

AI should not be used to skip thinking or submit copied answers.

---

## 🤝 7. Maintain Professional Communication

All discussions, questions, feedback, and reviews should remain respectful and focused on learning.

---

# 📅 Weekly Submission Expectations

At the end of each week, each member should submit:

- all daily completed work
- weekly REFLECTION.md
- updated GitHub repository
- cleaned folder structure
- corrected files after feedback

Before submitting, confirm:

- [ ] Completed analysis sheet is uploaded

- [ ] Insight summary is written
